01 / In a few words

A different balance between readability and precision.

Incan is a statically typed programming language with readable source, native compilation and Rust interoperability—being developed with a future of more inspectable, AI-assisted software development in mind.

Python shows how readable syntax can make software easier to author and understand. Rust brings static guarantees, native execution, and an established library ecosystem. Incan explores its own way of bringing these strengths together.

The goal is not simply to imitate either language. It is to build a coherent language and toolchain that keep application logic readable while making more of the underlying mechanics explicit and inspectable.

Prepared for the 0.6 website launch. This preview describes the intended release direction; the release notes will record what ships.

Short description

Incan is a modern, statically typed programming language for building native software. It brings readable source and explicit types together with Rust interoperability. Oven provides the shared project and build system, with Incan and Rust code living side by side.

04 / AI-first vision

Build software that people can inspect and verify.

Code is easier to generate.
Evidence matters.
Human + agent · Shared project model

Incan’s longer-term vision is for developers and AI agents to work from a shared understanding of a project. Rather than treating generated code as the end result, the workflow should make it easier to examine proposed changes, understand their impact, run tests, and review evidence.

This direction informs the language, compiler feedback, project model, and tooling. It is an evolving vision: not every part of the described workflow is available today.
