# Incan version of the Incapunk 2.0 welcome page

This directory contains generated output from [`tools/welcome`](../../tools/welcome/README.md). Rebuild with `tools/welcome/build` from the repository root; edit the Incan sources instead of this HTML, CSS or browser modules. The original HTML prototype remains beside it at `../obsidian/`.

The page is authored in Incan and lowered through a pinned Pallay foundation plus a generic browser adapter. The browser executes generated HTML/CSS/JavaScript. The cube, wordmark, Incus, architectural imagery, fonts and licenses retain the approved assets.
