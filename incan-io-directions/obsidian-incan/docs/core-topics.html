Overview

Getting started

Install Incan, set up your editor, and build a small program. Each chapter can also be read on its own.

  1. Install Incan — install the tools and run a sample program.
  2. Set up your editor — enable diagnostics, code navigation and formatting.
  3. Projects and configuration — organize source files and configure a project.
  4. Build and run with Oven — check code, run programs, build executables and run tests.
  5. Manage dependencies — use Incan libraries and Rust crates.

Put it into practice

Your first project walks through a greeting program and its tests. Download the complete project to follow along, then try the exercise at the end.
