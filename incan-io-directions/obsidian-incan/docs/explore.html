About this preview

This is a content experiment covering three topics, not the complete documentation. The guides assume you can already read a small program. Each topic links practical examples to a single home for its detailed contracts.

The Date API page is an authored preview of future source-generated documentation. Its signatures were checked against the local Incan source; it is not output from the upcoming API generator. The Oven walkthrough retains the documented 0.5 command baseline. The separate 0.6 architecture describes the developing compiler design.
