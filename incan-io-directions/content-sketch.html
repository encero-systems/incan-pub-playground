This is Incan.

model User:
    name: str

def greet_user(user: User) -> str:
    return f"Hello, {user.name}!"

def main() -> None:
    user = User(name="Incan")
    println(greet_user(user))

Named data. Typed functions. Clear structure.

Create a project. Run it. Test it. Build a native binary.

incan new hello --yes
cd hello
incan oven bake --project .
incan run
incan test
incan build --release
