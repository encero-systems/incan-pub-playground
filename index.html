About this Loaf

memchr provides fast byte search routines for Rust, with portable and platform-optimized implementations. This Loaf retains the upstream package’s sources for use with Oven.

  • Single-byte searchFind the first or last occurrence of a byte.
  • Byte setsSearch for any of a set of bytes.
  • Substring searchFind a subsequence of bytes.
