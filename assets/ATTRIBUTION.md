## Static package documents

Bundled author READMEs are extracted from the checksum-verified adopted source archives. Each package's license expression and upstream repository are displayed on its page. See `assets/site/packages.json` for file digests, source archive digests and recorded VCS commits.

Compact and full download plots under `assets/site/charts/crates-io/` depict the collected daily values in that same frozen bundle; they are quantitative plots, not generated illustrations.

The local Markdown renderer is markdown-it 14.1.0 (MIT), pinned in package-lock.json.
