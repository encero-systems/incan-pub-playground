03 / Crumb

Typed binary

One typed model. Two representations.

The same values.
In binary.

Crumb is the binary representation of the typed value model shared with .COMIC. The types, fields and values keep the same meaning.

A value carries its type description or is explicitly bound to one. Reference values stay references; reading them does not fetch their targets.

Row codeccrumb-row/1
Keeps each record’s typed cells together.
Column codeccrumb-columns/1
Stores ordered records by field, with bounded blocks for selecting values.

Experimental codec profiles · the format is still a draft.

Two forms. One meaning.

The core is language-neutral. Incan is the first implementation, currently in progress.
