# Crumb companion identity

The mark shares the .COMIC family's heavy italic lettering, cream panel, ink outline and offset shadow. Fitted teal cells distinguish the binary representation. The mark is a geometric companion concept, not a database or a literal food illustration.

`build-logo.py` outlines the bundled Bangers glyphs and combines them with exact SVG geometry. The wordmark needs no browser font download. The Bangers OFL license is retained with the bundled font. Install the pinned tooling in an isolated environment and run this script to regenerate `static/crumb-logo.svg` and `static/crumb-symbol.svg`. This tooling is separate from the native Incan site build.

Added 10 November 2026 as a companion to the immutable `comic-style-edition-02-20261109` baseline. That tag is unchanged.
