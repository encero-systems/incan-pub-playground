# Incan.pub design playground

An unfinished HTML design study for Incan.pub. This is a separate review surface, not the production registry website.

The package page uses a frozen local snapshot of the memchr 2.8.3 registry record. It distinguishes the authoritative Git index from source archives and compiled units stored in org-level GitHub Packages.

Open the GitHub Pages site to review the design. Search is scoped to the single example package; no backend or live registry resolution is connected.
